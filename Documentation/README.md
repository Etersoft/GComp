# Документация GComp 2.2.15

Описания форматов 1С:Предприятия 7.7, собранные авторами GComp и проекта
1L в 2004 году, и тексты лицензий. Они описывают сами потоки 1С, а не
дерево выгрузки GComp, поэтому годятся и для GComp 3. Имена свойств в
дереве GComp 3 указаны в примечаниях с пометкой «2026».

## Файлы

| Файл | Содержание |
| --- | --- |
| `txt/MD_Formats.txt` | Поток метаданных (Main Metadata Stream): константы, справочники, документы, регистры, расчёт, календари |
| `txt/DlgForms.txt` | Поток диалоговой формы: заголовок длины, параметры формы, колонок и элементов, флаги, горячие клавиши |
| `txt/Interfaces.txt` | Интерфейсы: команды, меню, панели кнопок |
| `html/index.html` | Оглавление HTML-версии |
| `html/dialogstream.html` | Dialog Stream 1.6 — HTML-переработка `DlgForms.txt` |
| `html/interface.html` | Интерфейсы 1.2 — HTML-переработка `Interfaces.txt` |
| `html/moxcel.html` | Формат таблиц moxcel (`*.mxl`) 1.11; рисунки `mxl_*.png`, таблица цветов `colours.html`/`colours.txt` |
| `html/rights.html` | Права пользователей (`UserDef/Page.2`) 1.2 |
| `html/gnu_fdl.html` | GNU Free Documentation License 1.2 |
| `txt/license.txt` | Условия распространения GComp |
| `txt/gnugpl.eng.txt`, `txt/gnugpl.rus.txt` | GNU GPL версии 2 и её русский перевод |

Справка по ключам командной строки — в `../ReadMe.txt`, это вывод
`gcomp -h` версии 3.0.

## Откуда взялся HTML

Текстовые описания `DlgForms.txt` и `Interfaces.txt` написаны авторами
GComp (Дмитрий Реутов, Алексей Диркс, Фёдор Езеев и другие, см. заголовки
файлов) и распространялись на http://1c.alterplast.ru/gcomp/. В мае 2004
года Дмитрий Павлюк, участник проекта 1L (http://sourceforge.net/projects/lproject),
вручную переоформил их в HTML: добавил оглавление, раздел истории и
таблицы вместо выровненного табуляциями текста, и выпустил под GNU FDL.
Разметка затем прошла через HTML Tidy for Windows, о чём говорит метатег
`generator`. Описания moxcel (Дмитрий Павлюк и Евгений Пивнев) и прав
(Дмитрий Павлюк) существуют только в HTML. Текстовые файлы GComp продолжали
дополняться (`DlgForms.txt` датирован в архиве 2.2.15 октябрём 2006 года,
HTML-страницы — июнем 2004): раздел о доп. флагах, которые нельзя задать в конфигураторе,
был только в `DlgForms.txt` и перенесён в `dialogstream.html` в 2026 году.

Адреса alterplast.ru, 1l.w4b.ru и почтовые адреса авторов давно не
работают; они оставлены как часть истории документов.

## Изменения 2026 года

- Файлы переведены из CP1251 (ReadMe.txt — из CP866) в UTF-8 с концами
  строк LF, HTML-страницы объявляют `charset=utf-8`.
- Исправлены опечатки и битые ссылки: на `gnu_fdl.html` (имя файла
  отличалось регистром, а в `moxcel.html` и `rights.html` ссылка вела на
  локальный диск автора), на рисунок `mxl_bgc.png` и якорь цвета шрифта в
  `moxcel.html`. В оглавление добавлены таблица цветов и FDL.
- Параметры шрифта формы (1–14) и элемента формы (25–38) расписаны как
  поля структуры LOGFONT. Прежнее описание ошибочно называло жирностью
  параметр 13 формы; это параметр 5 (`lfWeight`). В HTML-таблице элементов
  был пропущен параметр 24 («не сохранять при сохранении настроек»), из-за
  чего описание шрифта сдвинулось.
- Доп. флаги элементов описаны как стиль окна Windows (`WS_`, `BS_`,
  `SS_`, `ES_` и т. д.), модификатор горячей клавиши — как поле `fVirt`
  структуры ACCEL, а «скан-код» — как код виртуальной клавиши.
- Оставшийся устаревший дубль справки `txt/ReadMe.txt` удалён.

## Лицензии

`txt/*.txt` распространяются на условиях GNU GPL, как и GComp (см.
`txt/license.txt` и `../README.md`). HTML-документы 1L — на условиях GNU
Free Documentation License версии 1.2 или любой более поздней, без
неизменяемых разделов и текстов обложки (`html/gnu_fdl.html`).
