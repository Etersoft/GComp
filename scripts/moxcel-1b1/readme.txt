
Пример конвертора mxl в xml.
Скрипт предполагает, что конвертируемый mxl лежит в том же каталоге, что и
сам скрипт, и что этот xml называется Page.mxl

2026: скрипт для Python 2. Запуск: python2 mxl2xml.py ФАЙЛ.mxl, результат
пишется в ФАЙЛ.mxl.xml; без аргумента берётся Page.mxl. Образец Page.mxl из
архива GComp 2.2.15 (печатная форма счёта из чужой конфигурации) в
репозиторий не взят; можно взять таблицу .mxl из выгрузки GComp.
