## Введение

Данный документ описывает структуру файлов "\*.md/UserDef/Page.2/Page.\*". Являющимся набором прав того, или иного пользователя.\
Файл прав состоит из заголовка, в котором указывает количество блоков (наборов) прав идущих после. Каждый блок прав состоит из своего заголовка, в котором указывается, тип набора (например Справочник или Документ), его идентификационный код (Код МД) в потоке метаданных, и количества содержащихся в нем свойств. Если "Код МД"=0, то это общий набор для всех по умолчанию.\
Краткие примечания:

- Если в блоке прав не менялись значения по умолчанию, то данный блок не сохраняется. Кроме общего блока, он сохраняется всегда.\
- Если один раз изменить некий блок права, то запись о нем остается постоянно.
- Новые данные добавляются в конец файла.
- Код МД - идентификационный номер в потоке метаданных. Для общих прав он равен 0.
- Количество в блоке свойств не обязательно постоянно.

## Структура файла

Заголовок:

| Смещение | Длина | Значения | Наименование       |
|----------|-------|----------|--------------------|
| 0x00     | 1     | 6        | ?                  |
| 0x01     | 4     | 0        | ?                  |
| 0x05     | 4     | КБ       | Кол-во блоков прав |

Блок (набор) прав, повторяющийся КБ раз:

| Смещение | Длина | Значения | Наименование              |
|----------|-------|----------|---------------------------|
| 0x00     | 4     |          | [Тип набора прав](#типы-наборов-прав) |
| 0x04     | 4     |          | Код МД                    |
| 0x08     | 4     | КС       | Кол-во свойств            |

Свойства прав, повторяющийся КС раз, для каждого блока:

| Смещение | Длина | Значения    | Наименование             |
|----------|-------|-------------|--------------------------|
| 0x00     | 4     |             | [Тип св-ва прав](#типы-свойств-прав) |
| 0x04     | 4     | 0-Нет, 1-Да | Значение св-ва прав      |
