Распространяется на условиях GPL, см. [licenses/license.txt](licenses/license.txt).
Документ сделан из `MD_Formats.txt` GComp 2.2.15 (декабрь 2004); авторы в
файле не указаны. © 2026 Виталий Липатов — перевод в Markdown.

Поток метаданных — текст в фигурных скобках; его длина записывается тем же
заголовком, что и у [потока диалоговой формы](dialog-forms.md#заголовок-потока).
Ниже приведена грамматика списков объектов и значения их параметров по
порядку. Заголовок потока (`MainDataContDef`), описание конфигурации
(`TaskItem`) и запись `CRC` описаны в [md-file.md](md-file.md#main-metadata-stream).

Примечания с пометкой «2026» добавлены по коду GComp 3 и по выгрузке 430
конфигураций и внешних отчётов; там же сказано, какие значения встречаются у
неизвестных параметров.

## Некоторые общие компоненты

```
СсылкиНаОбъекты = {"<param1>", "<param2>", "<param3>", "<param2>", {"Refers" [, {"<ID1>"}, {"<ID2>"} ... {"<IDn>"}]}}
```

| № | Описание |
| --- | --- |
| 1 | Числовой идентификатор (внутренний) |
| 2 | Текстовый идентификатор (то, что видно в конфигураторе) |
| 3 | Комментарий |
| 4 | Синоним |

ID1 ... IDn - числовые идентификаторы объектов

Если этот объект входит в состав другого объекта, то первые 4 параметра - пустые. Но они м.б. и непустыми, если объект сам по себе просто набор ссылок, как например графа журнала документов.

```
ПравилаМиграции = {"Distribution ruler", "<param1>", "<param2>", "<param3>"}
```

**Описание правил миграции**

| № | Описание |
| --- | --- |
| 1 | Область распространения: W - все информационные базы, L - место создания, M - место создания и центр |
| 2 | Коды дополнительных ИБ (поле "дополнительно" в настройках правил миграции): строка |
| 3 | Автоматическая регистрация изменений: 1 или 0 |

\*примечание: если параметры миграции отсутствуют, то 1С будет считать, что ПравилаМиграции = {"Distribution ruler", "W", "", "1"}
